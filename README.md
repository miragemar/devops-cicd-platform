# DevOps CI/CD Platform

Навчальний портфоліо-проєкт, присвячений автоматизації тестування, контейнеризації та безперервної інтеграції застосунку з використанням DevOps-інструментів.

## Про проєкт

**DevOps CI/CD Platform** — це REST API, створений на Python із FastAPI, контейнеризований за допомогою Docker та інтегрований із GitHub Actions.

Проєкт демонструє базовий цикл CI: встановлення залежностей, перевірку якості коду, запуск автоматизованих тестів і збирання Docker-образу.

## Реалізовані можливості

- REST API на FastAPI.
- Ендпоїнти для перевірки стану сервісу та отримання його версії.
- Автоматизовані тести за допомогою pytest.
- Перевірка якості коду за допомогою Ruff.
- Контейнеризація за допомогою Docker.
- Запуск контейнера від непривілейованого користувача.
- CI-workflow на GitHub Actions.

## Як працює CI

Після `push` або створення `pull request` GitHub Actions запускає workflow із файлу `.github/workflows/ci.yml`.

```text
Git Push / Pull Request
          |
          v
    GitHub Actions
          |
          v
  Встановлення залежностей
          |
          v
    Перевірка Ruff
          |
          v
   Запуск тестів pytest
          |
          v
   Збирання Docker-образу
```

## API

| Метод | Ендпоїнт | Опис |
|---|---|---|
| GET | `/` | Інформація про сервіс і його стан |
| GET | `/health` | Перевірка стану застосунку |

## Локальний запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/miragemar/devops-cicd-platform.git
cd devops-cicd-platform
```

### 2. Створення віртуального середовища

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Встановлення залежностей

```bash
python -m pip install -r requirements-dev.txt
```

### 4. Запуск застосунку

```bash
uvicorn app.main:app --reload
```

Після запуску:

- API: http://127.0.0.1:8000/
- Health check: http://127.0.0.1:8000/health
- Версія: http://127.0.0.1:8000/version
- Документація: http://127.0.0.1:8000/docs

## Тестування

Запуск автоматизованих тестів:

```bash
python -m pytest -v
```

Перевірка якості коду:

```bash
ruff check .
```

## Запуск через Docker

Збирання образу:

```bash
docker build -t devops-cicd-platform:1.0.0 .
```

Запуск контейнера:

```bash
docker run --rm -p 8000:8000 --name devops-api devops-cicd-platform:1.0.0
```

Після запуску API буде доступне за адресою http://localhost:8000/.

Контейнер запускає застосунок від окремого непривілейованого користувача `appuser`.
